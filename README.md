# meldtree

Meld lightweight tree statistics from stdin samples.

**Site:** https://theworker02.github.io/meldtree/

## Install / run

```bash
git clone https://github.com/theworker02/meldtree.git
cd meldtree
node src/cli.js
node --test
```
